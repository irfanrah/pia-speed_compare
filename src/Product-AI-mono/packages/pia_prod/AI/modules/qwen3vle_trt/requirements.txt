# -- TensorRT runtime ---------------------------------------------------------
# Traced from: trt/engine.py (VisionEngine, TransformerEngine), trt/model.py,
#              export/c_export_onnx_to_trt.py. Must match the version used to
#              compile the engines on the export host.

# -- ONNX -------------------------------------------------------------------
# Traced from: export/a_export_to_onnx.py + export/c_export_onnx_to_trt.py

# -- Qwen3-VL chat templating -------------------------------------------------
